# 예정 작업과 미해결 항목

아직 고치지 않은 결함, 구조 개선, 확장 계획을 한곳에 둡니다. 항목을 처리하면 이 문서에서 지우고 변경 내용은 [변경 기록](../CHANGELOG.md)에 적습니다. 과거 경과는 Git 이력에 있습니다.

## 미해결 결함

| ID | 중요도 | 내용 | 위치 | 수정 방향 |
|---|---|---|---|---|
| N6 | P3 | WSL VM이 내려가면 알림이 오지 않습니다. Guard 표본 루프의 정지는 systemd watchdog이 다시 시작합니다 | Windows 측 | Windows 예약 작업이 Guard의 생존 표식을 확인 |


## 구조·효율 개선

| ID | 내용 |
|---|---|
| S1 | `daemon.sample()` 한 함수에 수집·평가·경보 유지·구형 알림·저장이 섞여 있고, 회복 판정이 `sample`과 `reconcile` 두 곳에 있습니다. 데몬은 구형 알림 경로(`notify=True`)를 쓰지 않습니다 |
| S2 | 경보 이력(에피소드) 조회는 아직 보존 기간 전체의 원본 이력을 읽습니다. `history.py`의 `_file_cache`와 `OwnerData`의 프로세스 내 캐시는 소유자 worker가 호출마다 새 프로세스라 적중하지 않으므로 제거 대상입니다 |
| S4 | 전달 worker가 2초마다 여러 파일을 읽고, `/proc` 스캔이 다른 사용자 프로세스까지 읽은 뒤 UID로 거릅니다 |

## 마일스톤

마일스톤 하나가 작업 브랜치 하나입니다. 릴리스·원격 push·운영 배포는 요청이 있을 때 합니다.

| 순서 | 이름 | 다루는 항목 | 선행 |
|---|---|---|---|
| M4 | 판정 구조 정리 | S1 | 없음 |
| M6 | 조회 비용 | S2(경보 이력, 적중하지 않는 캐시 제거), S4, 컨트롤러 비용 측정 | 없음 (병행 가능) |
| M7 | Windows 동반 구성요소 | VM 정지 감시(N6), 로그온 작업 설치 스크립트, 절전·재개 기록 | 없음 |
| M8 | 전환 평가와 이름 변경 | 소유자 worker·컨트롤러의 Go 전환 평가, `windows-wsl-resource-guard` | M6, M7 |

호스트 메모리 경보는 드라이브와 같은 방식(마지막 확인값으로 유지)으로 넣어 `sample()`에 유지 분기를 추가하지 않았습니다.

### 호스트 관측에서 남긴 것

호스트 상태는 `hostbridge.py`가 PowerShell 한 번(약 1초)으로 수집해 `metrics.host`에 두고 화면에 표시합니다. 다음은 아직 하지 않았습니다.

- 호스트 값의 이력 파일. 추세·예측처럼 읽는 기능이 생길 때 낮은 주기의 별도 파일로 추가합니다.
- interop이 PowerShell을 기동하지 못하고 `Invalid argument`로 끝나는 일이 간헐적으로 있습니다(실측 9회 중 1회). 원인은 확인하지 못했고, 한 번 다시 시도한 뒤에도 실패하면 사유를 표시합니다.
- 확인하지 못한 것: 시간 제한으로 중단한 뒤 Windows에 PowerShell 프로세스가 남는지, 분당 조회가 잠든 디스크를 깨우는지.
- 다른 이름의 VHD 파일을 쓰는 배포판은 자동 탐지하지 않습니다(`wsl_vhd_path`로 지정).

### M7·M8 — 구현 언어

전면 재작성은 하지 않습니다. 수집 안정성 문제는 설계에서 나왔고, 호스트 수집 비용은 PowerShell 기동이라 호출하는 쪽 언어와 무관합니다. 컴파일 언어는 두 곳에만 순서대로 검토합니다.

1. Windows 동반 구성요소(M7)는 Go 단일 실행 파일을 검토합니다. Windows에 런타임을 설치하지 않아도 됩니다. 서명 없는 실행 파일에 대한 Windows 보안 기능의 반응은 먼저 확인해야 합니다.
2. 소유자 worker와 컨트롤러(M8)는 M7의 운영 결과와 M6의 측정값을 보고 정합니다. 운영 실측에서 컨트롤러 cgroup은 평균 3.7% 코어(Guard는 0.48%)를 썼고 최고 메모리가 유닛의 `MemoryHigh=192M`에 도달했습니다. 원인별 비중은 M6에서 측정합니다.

구성요소를 하나씩 바꿀 때의 기준은 [저장 형식과 컨트롤러 요청](data-formats.md)입니다.
