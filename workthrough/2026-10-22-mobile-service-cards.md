# 모바일 서비스 이름 잘림 수정

## 원인

사용자 캡처의 Pi Web 위는 LLM Usage, Devin Web 아래는 Paseo였다.
모바일 카드가 `grid-template-columns: 1fr auto`로 이름과 상태를 같은 행에 배치했다.
오른쪽 열의 상태 배지 또는 메모리 추세·한도 표시가 가로폭을 차지하면 이름과 자동 실행 셀 폭이 0px이 됐다.
실제 운영 390px 화면에서 두 서비스의 grid가 `0px 342px`인 것을 확인했다.
페이지 전체의 가로 넘침과 텍스트 존재만 확인한 이전 검증으로는 셀 내부 잘림을 발견하지 못했다.

## 변경과 검증

- 1000px 이하 서비스 카드는 이름, 상태, 자동 실행, 메모리, 조작을 각각 독립된 행에 둔다.
- 이름이 카드 너비를 사용하고 긴 문자열은 줄바꿈한다. 상태 배지와 메모리 표시도 줄바꿈을 허용한다.
- PC의 상태 셀도 여러 연결 배지를 줄바꿈해 잘리지 않게 했다.
- 브라우저 회귀 검증은 이름 텍스트의 실제 경계, 제목 셀 너비, 모든 셀의 내부 넘침을 확인한다.
  상태 미확인·실패·꺼짐·오래됨을 포함해 320px·390px·768px에서 검사한다.
- 실제 운영 데이터를 읽되 CSS만 로컬 수정본으로 교체한 브라우저에서 320/390/412/768/1000/1440px를 확인했다.
  수정 후 390px의 LLM Usage와 Paseo 제목 셀은 각각 352px이며 이름·자동 실행·상태·메모리 셀에 잘림이 없다.
  최종 수정본의 390px 다크 테마와 1440px 상태 셀도 확인했다.
- `node --check wsl_resource_guard/web/app.js`, `tests/browser_offline.py` 모두 통과했다.

## 운영 적용

수정은 CSS와 회귀 테스트이며 Paseo 프로세스 변경은 필요하지 않다.
운영 CSS는 root 소유 설치본이므로 관리자 인증 후 기존 웹 설치기로 반영해야 한다.
현재 단계에서는 로컬 수정본 검증과 운영 반영을 구분한다. 적용 완료 시 이 기록을 갱신한다.
