# 0.2.3 릴리스

## 범위

Paseo 서비스 관리·연결 검사와 모바일 서비스 이름 잘림 수정을 하나의 패치 릴리스로 게시한다.
버전은 pyproject, Python 패키지, uv 잠금을 0.2.3으로 맞춘다.
앞서 운영에 적용한 기능 및 CSS 커밋과 GitHub 릴리스·운영 버전 갱신을 구분해서 기록한다.

## 변경

- Paseo 유닛 예제, 등록 정보, HTTP·로컬·릴레이 검사와 상태 UI.
- 모바일 이름 영역이 0px로 축소되는 카드 레이아웃 수정, PC 상태 배지 줄바꿈.
- 서비스명 텍스트 경계·셀 내부 넘침에 대한 PC/모바일 회귀 검사.
- 격리 Paseo 서비스 수명주기 검사를 릴리스 공통 CI에 연결. 새 사용자 홈에서도 실행할 수 있도록 테스트 유닛 디렉터리를 준비한다.
- CHANGELOG와 배포 압축본 예제 버전 갱신. 첫 PR CI의 개발 의존성 감사에서 certifi 2026.7.22의 `PYSEC-2026-4320`이 발견돼 해당 패키지만 2026.10.19로 갱신했다. 웹 런타임 의존성 감사는 통과했다.

## 검증·게시 상태

기능 및 운영 검증은 `2026-10-22-paseo-service-management.md`, `2026-10-22-mobile-service-cards.md`에 기록돼 있다.
이번 버전 변경은 별도 PR에서 전체 CI를 확인한 뒤 병합하고 태그 릴리스의 필수 검사를 통과시켜 게시한다.
게시된 압축본의 SHA256SUMS와 SOURCE manifest를 확인한 뒤 운영 버전을 갱신한다.
단계별 실제 결과는 완료 후 이 파일에 갱신한다. 이 문장 자체는 게시나 운영 버전 갱신의 완료 증거가 아니다.
